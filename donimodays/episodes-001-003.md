## Tips for generating these

- Make a single character image of Donimo first. Use it as the image reference
  for every clip if your tool supports image-to-video.
- Keep each clip to one action. Simple shots look better and stay more consistent.
- If a character changes look between shots, regenerate rather than keep it.
  Consistency is what makes a character channel feel professional.
